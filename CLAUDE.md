# Femme Ferments

Nonprofit wine organization website — "Beauty in the Broken Glass"

## Project
- **Client**: Femme Ferments (Willamette Valley, OR)
- **Type**: Pro bono nonprofit website build by Effulgent Point
- **Repo**: github.com/Effulgent-Point/femmeferments
- **Current site**: femmeferments.com (GoDaddy/Wix — being replaced)

## Design Rules
- NEVER use pale purple, pastels, or whitewashed aesthetics
- Use rich jewel tones: deep teal, emerald, sapphire, ruby, amber, purple
- Dark backgrounds with vibrant color accents
- Inspiration: bottle label mosaic art (broken glass in rainbow jewel tones)
- Core motif: "Beauty in the Broken Glass" — shattered glass as beauty metaphor

## Architecture
- Next.js 16 static export + JSON content store + PHP API
- Adapted from soccersite CMS pattern (see reference/design-brief.md)
- Hosted on GoDaddy with built-in admin panel for client editing
- No Wix — they don't support custom HTML upload

## Footer Requirement
Every page must include: "Made with ❤️ by Effulgent Point" linking to https://effulgentpoint.com/

## Brand Details
- Tagline: "Beauty in the Broken Glass"
- Mission: 100% of profits empower women
- Wines: Albarino "Power & Grace", Pinot Noir "Hope & Grit"
- Location: Willamette Valley, Oregon
