# Femme Ferments glass section assets

Generated from `logo_orig.jpg` at 1275×945px.

## Folders

- `canvas_png/` — 18 transparent PNG layers on the original full canvas. Stack them at `left:0; top:0` and they align perfectly.
- `tight_png/` — cropped transparent PNG chunks for lighter per-page use. Use `metadata.json` bbox values to place them back into the original layout.
- `masks/` — alpha masks for the full glass and each section.
- `svg/section_clip_paths.svg` — simplified clip paths for the same sections. PNG alpha masks are the source of truth.
- `previews/` — numbered overlay, contact sheet, and a reassembled verification render.
- `metadata.json` — bbox, anchors, average colors, source seeds, and file paths.
- `web_usage.css` + `web_usage_snippet.html` — starter animation scaffolding.

## Notes

The split uses 18 larger regions. Region boundaries are generated by marker-based watershed segmentation using visual seed points, so the cuts prefer the existing grout/crack lines instead of straight rectangular slices. For exact pixel reproduction, use the PNG layers and masks.
